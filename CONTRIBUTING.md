# Contributing

Thanks for your interest in D2R Ultimate Seed Finder.

## Bug reports

Please open a GitHub issue and include:

- app version
- Windows version
- what you were doing when the problem happened
- whether the issue happens again after restarting the app
- a screenshot or copied error text when available
- the seed number when a problem is seed-specific

Repository: https://github.com/Beez3-A/D2R-Ultimate-Seed-Finder

## Feature requests

Feature requests are welcome, especially when they improve:

- seed-search workflow
- route comparison
- database usability
- reproducibility
- release/build reliability

Please avoid proposing changes that would turn the tool into an online automation/bot or a save-file editor. The project is intended as an offline map-seed analysis utility.

## Pull requests

Before opening a pull request:

1. Keep changes focused.
2. Do not remove the existing regression/preflight safeguards without a strong technical reason.
3. Do not silently change route definitions or ranking semantics.
4. Describe how the change was tested.
5. For scanner/ranking changes, include before/after examples or regression coverage where practical.
